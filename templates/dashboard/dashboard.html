Two scan modes, one dashboard

Start light, then go deep once you know where to look.

Passive

Quick Scan

Loads your pages and checks for misconfigurations, insecure cookies, and vulnerable JS dependencies — without touching your data.

  • Fast — completes in a couple of minutes
  • Safe — non-intrusive, read-only scanning
  • Covers configuration & informational issues
Active

Deep Scan

Submits forms and requests to actively test for SQL injection, command execution, and cross-site scripting.

  • Thorough — full-depth vulnerability coverage
  • Requires authorization on the target
  • May take up to an hour for full coverage
Coverage

Hundreds of checks, organized by category

A sample of what VulnEx tests for in every deep scan.

  • · Debug error messages exposed in responses
  • · Sensitive data leaked in URLs or referrer headers
  • · .env and .htaccess file exposure
  • · Cookie poisoning and insecure cookie flags
  • · Private IP address disclosure
  • · Missing or misconfigured security headers
  • · Directory listing enabled
  • · Default or sample admin pages left accessible
  • · CORS misconfiguration
  • · SQL injection across form fields and parameters
  • · Command injection in user-supplied input
  • · LDAP and XPath injection
  • · Reflected XSS in query parameters
  • · Stored XSS in form submissions
  • · DOM-based XSS in client-side scripts
  • · Weak TLS/SSL cipher suites
  • · Expired or self-signed certificates
  • · Mixed content over HTTP

Plus hundreds more checks updated continuously as new CVEs are published.
